SuperGrok Build · xAI agent

How to use Grok with Unreal Engine 5.8 MCP

SuperGrok Build is xAI’s coding agent in the terminal. Unreal 5.8 already ships an MCP server inside the editor. Point Grok at that server and you can spawn, inspect, and light from a prompt — same bridge as the Office Hours video below, this time the client is Grok.

Install SuperGrok

Grok is not a plugin inside Unreal. It is a local TUI you launch from the project folder. The editor runs an HTTP MCP server on 127.0.0.1:8000. Grok talks to that server. Epic’s client-config generator writes JSON for Claude Code, Cursor, VS Code, Gemini, and Codex — not Grok. You add the server yourself with grok mcp add or a project .grok/config.toml.

You type SuperGrok Build Run grok from the folder that has your .uproject.

Editor Unreal Engine 5.8 Spawn, select, light, screenshot — one tool call at a time.
1 · Install Grok Windows PowerShell SuperGrok subscription, then: 
PS> irm https://x.ai/cli/install.ps1 | iex
PS> grok --version
PS> grok
First launch opens grok.com to sign in. macOS / Linux: curl -fsSL https://x.ai/cli/install.sh | bash.
2 · Enable MCP Three plugins, then auto-start Edit → Plugins: Unreal MCP, All Toolsets, Editor Tool Set. Restart. Then Edit → Editor Preferences → Model Context Protocol → Auto Start Server (port 8000, path /mcp). Output Log should show the server starting on port 8000.
3 · Point Grok at UE Project-scoped MCP From the project root: 
PS> grok mcp add --transport http --scope project unreal-mcp http://127.0.0.1:8000/mcp
Or commit .grok/config.toml: 
[mcp_servers.unreal-mcp]
url = "http://127.0.0.1:8000/mcp"
enabled = true
startup_timeout_sec = 30
tool_timeout_sec = 120
4 · Every session Unreal first, then Grok Open the .uproject. Wait for the MCP log line. Then from that folder run grok. In the TUI: /mcps → unreal-mcp [ready]. After any editor restart, press r to re-handshake. Optional: /grok-ue-mcp if you cloned the starter project below.

First prompts

Issue one ask at a time. Epic serializes tools on the game thread — stacking ten spawns in one prompt can hang.

  1. Health. “What MCP tools do you have from unreal-mcp?” then “List available Unreal toolsets.”
  2. Read. “What actors are in the current level?” “What do I have selected in the editor?”
  3. Write. “Spawn a static mesh cube at the world origin named GrokTestCube.” Then “Focus the viewport on GrokTestCube.”
  4. Save. Confirm the cube in Outliner and viewport, then Ctrl+S. You still open the editor yourself. MCP does not replace a restart.

If a cube does not appear in about a minute, the harness or the server is the problem — not the prompt. Filter Output Log by LogModelContextProtocol, then run grok mcp doctor unreal-mcp.

Office Hours · Unreal Engine 5.8

Getting Started with MCP

Epic’s August Education Office Hours: how the experimental Model Context Protocol plugin lets an AI agent work inside the editor the same way you do — spawn, paint, light, inspect — if you turn on the right plugins first.

Watch on YouTube

MCP is not a chatbot bolted onto Unreal. It is a server that starts inside the editor. Your coding agent — SuperGrok Build in the section above, Claude Code in this session, or Cursor, VS Code, Gemini, or Codex — talks to that server over local HTTP. The agent can then do editor work: right-click, drag from the Content Browser, spawn actors, set lights, make materials. 5.8 already ships the plugin. You bring the agent.

The Unreal MCP plugin itself has no tools. It is only the bridge. Tools come from toolsets. Skip those and the agent can connect and still do nothing. Enable three plugins, not the two the docs often mention: Unreal MCP, All Toolsets, and Editor Tool Set. Restart. Only after that restart does Model Context Protocol show up in Editor Preferences. Check Auto Start Server so you are not typing a console command every launch.

1 · What it is Bridge, not magic Server in the editor. Agent talks to it. Experimental in 5.8 — APIs can rename, drop, or grow. Ship on 5.8 if you depend on it.
2 · Setup Three plugins, then config Enable, restart, auto-start. Console: ModelContextProtocol.StartServer, then ModelContextProtocol.GenerateClientConfig ClaudeCode (or All). Launch the agent from the project root so it finds .mcp.json.
3 · First prompts Spawn, then color Sam’s first live ask: spawn cubes, color, lights at 0, 0, 100. If a simple material does not appear in about a minute, the harness or the server is the problem — not the prompt.
4 · Limits Too many tools Unreal exposes so much that it can blow the model’s context. Keep toolsets lean. Output Log + verbose MCP logging. MCP Inspector lists every tool and lets you call it with no agent in the way.

What the hour actually covers

About forty-five minutes of demo, then live Q&A. Third-person template, project named MCP, Blueprint defaults. After plugins and auto-start, the Output Log should say the server is transmitting to your LLM provider — that line is the proof it started. GenerateClientConfig writes the JSON the agent needs. If you are not sure which client, generate All.

Q&A: Fortnite / UEFN is not this plugin; there is a separate Python path. Context size is a known issue — Epic exposed more than many models can hold. State of Unreal has the bigger living-room-to-city MCP demo. Next office hours may hit MetaHuman, animation, Sequencer.
