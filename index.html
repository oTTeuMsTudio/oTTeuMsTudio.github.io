3D modeling

MeshForge in the browser

A polygonal modeler I wrote in Rust — object and edit mode, box tools, gizmos, undo, OBJ import and export. Now compiled to WebAssembly so it lives on this site, not only on the desktop.

Live Object and Edit mode Tab to switch. 1 / 2 / 3 for vertex, edge, face. G / R / S to transform.
Live Box modeling tools Extrude, inset, subdivide, fill, join, and a transform gizmo in the viewport.
Live Rust + wgpu in the browser Same editor as the desktop build, compiled to WebAssembly. Needs WebGPU or WebGL2.
