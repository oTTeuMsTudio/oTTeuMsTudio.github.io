Rust

Writing my own 3D modeler

I am writing a polygonal 3D modeler in Rust system-level code — mesh topology, GPU viewport, tools, and undo I own. Not a plugin, and not a script on top of someone else's editor. oTTeCAD is that workbench, compiled to WebAssembly so it runs on this site.

Now System-level Rust Native mesh data, wgpu GPU path, and tools written in Rust — not a high-level wrapper.
Live Object and Edit mode Tab to switch. 1 / 2 / 3 for vertex, edge, face. G / R / S to transform.
Live Same editor in the browser Desktop build compiled to WebAssembly. Needs WebGPU or WebGL2.
