# oTTeuM sTudio

Personal GitHub Pages site for **oTTeuM sTudio** — Unreal Engine game development beginner.

**Live:** https://otteumstudio.github.io

Home is three buttons: **Install SuperGrok**, **Try my Games**, and **Learn Rust**.

Static HTML/CSS/JS. GitHub Actions deploys `main` to Pages, and attaches the Windows zip from the `fgiu` release so visitors can download the game.

Games: [`games/`](https://otteumstudio.github.io/games/) — First Game in Unreal, packaged for Windows. Download `FGIU-Windows.zip`, unzip, run `FGIU.exe`. The old [`firstgame/`](https://otteumstudio.github.io/firstgame/) URL redirects here.

Rust: [`rust/`](https://otteumstudio.github.io/rust/) — writing a custom game engine with an editor like Fyrox, then oTTeCAD, a 3D modeler compiled to WebAssembly. The old [`modeling/`](https://otteumstudio.github.io/modeling/) URL redirects here.
