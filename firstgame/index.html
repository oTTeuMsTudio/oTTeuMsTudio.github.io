First game · August 2026

FHOU

My first playable in Unreal Engine 5. Third-person graybox, lime platforms, coins to pick up, a HUD, and a game-over widget. Not a shipped title — a first loop I can actually run.

Unreal Engine 5 Blueprints Third-person Standalone preview

What is in the build

A small loop, fully wired

Graybox on purpose. The 3D artist habit stays: scale and path first, pretty later. The new skill is making it play.

Playable BP_PlatformingCharacter Third-person mannequin on a lime playground — run, jump, camera.
Playable BP_Collectible + WBP_HUD Gold coins in the level and a counter on screen. Pick one up, the number moves.
Playable WP_Gameover A game-over widget so the loop can end, not just wander.
