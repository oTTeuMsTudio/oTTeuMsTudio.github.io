Top-down strategy / shooter

A short editor recording of how this game starts: Unreal Engine 5.8, the Top Down template, click-to-move, and the Blueprint input that sends the mannequin across the graybox.

This is the first session of a top-down strategy/shooter. Not a trailer — an explanation of the start. Engine 5.8, Blueprints first, graybox on purpose.

The map is the Top Down template: blue prototype volumes, ramps, a click destination on the floor. Play In Editor runs the mannequin. The last beat opens IA_SetDestination_Click (left mouse) and IA_SetDestination_Touch (touch) — the input that will grow into orders, then shooting.

Strategy and shooter share this camera and this click. Units and fire come after the body actually walks where I point.

The first loop of this game

Same rule as the last playable: scale and path before pretty. New rule: the camera looks down, and a click is an order.

Now Top-down camera Editor viewport and PIE both look down on the graybox — the angle this game will keep.
Now Click-to-move Left mouse sets a destination. The mannequin runs there. That is the first order.
Now Blueprint input Enhanced Input actions in Content / TopDown / Input — mouse and touch, no C++ yet.
Next Strategy, then fire Select units, give orders, then a shooter layer on the same top-down map.
